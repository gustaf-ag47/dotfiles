# Tier-0 bootstrap kit manifest.
#
# Format:  <source-path-on-a-live-machine>   <path-inside-the-kit>
#
# ONLY what a blank machine needs to become a member of the fleet. Everything
# else arrives afterwards via Syncthing ($SYNC) and restic. Keep this small:
# the kit is committed to a PUBLIC repo as ciphertext, so every entry is a
# thing you must be willing to have encrypted-at-rest in the open.
#
# Absent paths are skipped with a warning, so one manifest works across hosts.

# --- Syncthing --------------------------------------------------------------
# NOT the device identity. Copying cert.pem/key.pem makes the new machine BECOME
# the old device: two machines claiming one device ID corrupts cluster
# assumptions, and the old machine may still be running.
#
# A new machine should JOIN the mesh instead -- mint its own identity on first
# start, then be admitted by an introducer. Only the non-identity config travels
# in the kit, so the new node knows who its peers are.
#
# To replace a DEAD machine and inherit its identity, restore cert.pem + key.pem
# + config.xml from the restic backup instead. That is a deliberate, separate
# act, not the default path.
#
#   ~/.local/state/syncthing/cert.pem     syncthing/cert.pem   <- deliberately absent
#   ~/.local/state/syncthing/key.pem      syncthing/key.pem    <- deliberately absent

# The peer list DOES travel: device IDs are not secret (they are exchanged with
# peers by design) but a new node needs them to know who to connect to.
$DOTFILES/secrets/known-devices.txt      syncthing/known-devices.txt

# --- SSH ------------------------------------------------------------------
~/.ssh                                  ssh

# --- API tokens -----------------------------------------------------------
# Claude OAuth tokens. Rotatable, so acceptable in the kit.
~/cctoken                               cctoken

# --- GPG ------------------------------------------------------------------
~/.gnupg                                gnupg

# --- Deliberately NOT in the kit -----------------------------------------
# /var/lib/tailscale/tailscaled.state
#   Tailscale node identity is disposable. Mint a fresh, tagged, one-off
#   auth key at join time instead of carrying node state around.
